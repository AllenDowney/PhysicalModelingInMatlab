# Physical Modeling in MATLAB

*by Allen B. Downey*

```{image} https://greenteapress.com/matlab/cover_small.png
:alt: Cover of Physical Modeling in MATLAB
:width: 160px
:align: right
```

*Physical Modeling in MATLAB* is an introduction to programming and to modeling and simulation of physical systems, for people who have never programmed before. It assumes some calculus and basic physics.

## Two ways to use this book

**Read it here.** Each chapter is a page you can read in your browser, with the code, its output, and the figures. Solutions to the exercises are hidden; click to show them.

**Run the code online.** Each chapter is also a notebook you can run, change and run again in your browser, with GNU Octave, the free alternative to MATLAB. There's nothing to install and no account to create. [Run the code online](https://allendowney.github.io/PhysicalModelingInMatlab/run/), or use the "Run this chapter online" link at the top of each chapter.

You can also run the examples on your own computer, in MATLAB or GNU Octave: [download the code](https://github.com/AllenDowney/PhysicalModelingInMatlab/raw/master/PhysicalModelingInMatlab.zip).
